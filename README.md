File Wmath.exe is the 6-coordinates to 4-coordinates numeric data converter developed based on informations included in the file MethodDOI.pdf. File Ruch_robota.png shows movement of robot through 20 positions visualazed in 4-coordinates space used as an example of coordinates reduction. File Aircraft.png is another example of coordinates reduction applied to detect plane start anomalies. File GP.png shows the results of 6 to 4 coordinates reduction taking into account avarage values of temperature, humidity and rainfall as well as standard deviation values of each parameter.
